> A small tool that does one thing well.

## Install

```bash
npm install awesome-tool
```

## Usage

```js
import { run } from 'awesome-tool';

run({ fast: true });
```

| Option | Type | Default | What it does |
|--------|------|---------|--------------|
| `fast` | boolean | `false` | Skips the slow checks |
| `out` | string | `"dist"` | Where files go |
